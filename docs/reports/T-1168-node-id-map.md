# T-1168 — node id map: old -> new (activities-only step numbers)

Operator GO on T-1094 (2026-10-13). From this designer version on, only ACTIVITIES take a step number in a
node id (`<lane>_<n>_<slug>`, n counted over the lane's activities in x order); events and gateways carry a
type word instead (`<lane>_<start|end|gw|link|error|timer|message|ev>_<slug>`, `_2` for a second one with
the same word and slug in a lane). The committed corpus (examples/aef-processes/rendered/) was migrated by
renaming ids in place, nothing else; generated by tools/_t1168-node-id-map.mjs, which pairs old and new ids
through each node's uid, so a number reused for another node is never mapped by number.

Ids not listed are unchanged (activities before the first event or gateway in their lane). Edge ids
(`flow_N`) are unchanged.
