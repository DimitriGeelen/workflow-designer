## Does not hold: the Slug field is not styled like UID or Owner
Pixel samples from 1440, inside each field:

| field | background RGB | value text |
|---|---|---|
| Name (editable) | 29,34,48 | bright |
| Lane (editable) | 29,34,48 | bright |
| **Slug** | **27,31,44** | **bright (light grey)** |
| Display ID (read-only) | 22,25,34 | accent |
| UID (read-only) | 22,25,34 | dim grey |
| Owner (read-only) | 22,25,34 | dim grey |

At all three widths, the Slug box looks like the editable Name and Lane inputs, only slightly faded. It does not look like UID or Owner, which have the darker surface background and dim value text. The cause is in the code: the slug input only gets `readOnly`, `tabIndex=-1` and `style.opacity='0.75'`. It does not get the read-only styling that UID and Owner use. The hint does say how to change the slug, but on looks alone the field still reads as an editable input.

## Needed
Give the Slug input the same read-only styling as UID and Owner: the surface background (`var(--surface)`, about rgb 22,25,34) and the same dim value colour. Re-shoot the three widths.
