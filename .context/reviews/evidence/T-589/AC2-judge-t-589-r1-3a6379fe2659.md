## Judgement
Field name is sensible and the target (Watchtower component card route) is the right one and
resolves correctly. But the criterion's Expected ("Watchtower opens the component card") is NOT
reproducible by the steps given: the test harness serves the page from an origin with no /fabric
route, so the human would hit a 404 (a test-route artefact, not a code defect). The production
path (/designer on Watchtower) still serves a pinned build without this change, so the end-to-end
click has not been demonstrated on a page that both contains the change and is served by Watchtower.
