# T-111: Surface distribute-align-columns trade-off in editor tooltips

## Context

Follow-up from the T-110 corpus routing-debt sweep (`docs/reports/T-110-routing-debt-sweep.md`,
Finding 3 + Verdict): **Distribute evenly** and **Align columns** optimise orthogonal
properties (row rhythm vs column straightness). On a node that is both a row-mate and a
column-mate they can undo each other. The sweep's one actionable follow-up was to surface
that trade-off in the button tooltips so operators aren't surprised when applying one
appears to partially revert the other. Pure documentation change — two `title=` strings in
the toolbar; no editor logic touched (PL-005-safe).
