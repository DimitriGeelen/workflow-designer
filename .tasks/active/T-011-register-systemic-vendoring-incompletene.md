# T-011: Register systemic vendoring-incompleteness concern (F2/F4 + cross-project corroboration)

## Context

The `fw vendor` / `fw init` process ships an incomplete payload to consumer
projects — required runtime files are dropped. This project hit it twice
(F2: `orchestrator-mcp-baseline.yaml`; F4: `secret-scan.sh`), and a sibling
consumer (`fan-dashboard`) independently filed the same-class RCA to the
framework agent on 2026-06-05 ("`fw init` vendoring drops required runtime
files"). Same class hit 3× across projects → systemic. Now that onboarding is
complete, this upstream failure can finally be *recorded* (the recording that
the F5 onboarding gate previously blocked). The gap stays visible in our
register/Watchtower/audit until upstream ships the fix and we re-vendor.

**Symptom:** Fresh consumer projects are missing required runtime files after
`fw vendor` / `fw init` — first audit FAILs (F2: orchestrator-mcp-baseline.yaml)
and the pre-commit secret scan silently skips (F4: secret-scan.sh absent).

**Root cause:** The vendor payload definition (`do_vendor()` in upstream `bin/fw`)
does not enumerate all files the runtime/hooks depend on — required artifacts are
omitted from the copy set. It's a packaging-completeness gap, not a logic error.

**Why structurally allowed:** Nothing cross-checks "files the framework references
at runtime" against "files the vendor payload ships." A referenced-but-unshipped
file degrades silently (audit FAIL looks like a consumer problem; the secret-scan
hook prints "scanner not found (skipping)" instead of hard-failing). No vendor
manifest / completeness test exists, so the drift is invisible until a consumer
trips over it — and it recurred across ≥3 consumers (us ×2, fan-dashboard).

**Prevention:** (upstream) ship the missing files AND add a vendor-completeness
check (a manifest test, or make referenced-but-missing hooks hard-fail not skip).
(local) G-001 keeps the gap visible in our register/audit until upstream fixes it
and we re-vendor — so it can't silently persist here.
