# T-036: Validator: port parallelGateway + reachability checks to BPMN-XML form (format parity)

## Context

Format-parity fix. T-034/T-035 added parallelGateway + reachability checks to the
YAML `Validator` only; the `XmlValidator` (the BPMN-XML export form the designer's
Save actually emits) never got them — a real asymmetry, since schema.md §7.3 rules
should hold for both produced formats. This ports the equivalent structural checks
to the XML validator (WARN, pure-structural, no `aef:` reading):

- **W-XML-PGW-CONDITION** — a `sequenceFlow` out of a parallelGateway carries a
  `<bpmn:conditionExpression>` (ignored at a parallel fork)
- **W-XML-PGW-NOOP** — a parallelGateway with ≤1 in and ≤1 flow
- **W-XML-PGW-UNBALANCED** — a parallel fork with no matching join (or vice versa)
- **W-XML-UNREACHABLE** — a flow node not reachable from a start event
- **W-XML-DEADEND** — a flow node that cannot reach an end event

Existing XML corpus/fixtures stay clean. Product-side only.
